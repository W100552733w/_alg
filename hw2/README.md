# 習題 1：查表法計算 2^n 與執行效率分析

## 程式說明
本專案實作四種計算 $2^n$ 的方法，並在 $n = 100$ 時測試各方法的執行效能與可行性。

### 實作方法
1. **方法 1 (`2**n`)**：使用 Python 內建次方運算子。
2. **方法 2a (雙重遞迴)**：`power2n(n-1) + power2n(n-1)`
3. **方法 2b (單次遞迴)**：`2 * power2n(n-1)`
4. **方法 3 (遞迴 + 查表法)**：以 Dictionary 快取已經計算過的 `power2n(k)`。

---

## 執行效率與複雜度分析

| 方法 | 時間複雜度 | 測試 $n = 100$ 結果 | 說明 |
| :--- | :--- | :--- | :--- |
| **方法 1** | $O(1)$ ~ $O(\log n)$ | **極快** (< 0.0001 秒) | Python 內部底層優化，效率最高。 |
| **方法 2a** | $O(2^n)$ | **跑不出來 (TLE)** | 指數級展開，計算次數達 $2^{100}$ 次，無法在有限時間內完成。 |
| **方法 2b** | $O(n)$ | **快** (< 0.0001 秒) | 線性遞迴 100 層，在 Python 遞迴深度限制（預設 1000）內順利執行。 |
| **方法 3** | $O(n)$ | **快** (< 0.0001 秒) | 藉由快取消除了方法 2a 的重複子問題，將複雜度從指數級降為線性。 |

## 結論
- **速度排行**：方法 1 > 方法 2b ≈ 方法 3 >> 方法 2a。
- **無法完成**：**方法 2a** 在 $n = 100$ 時完全無法產出結果。
- **查表法的價值**：透過 Memoization 技巧，將指數時間複雜度 $O(2^n)$ 的遞迴巨幅降至線性時間 $O(n)$。
