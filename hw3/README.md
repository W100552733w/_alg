# 第三週習題：列舉 + 暴力法求解 SAT 問題

## 1. 原理說明
布林可滿足性問題（Boolean Satisfiability Problem, SAT）是第一個被證明為 NP-Complete 的經典問題。
本專案採用最直觀的**暴力法（Brute Force）**：
- 對於包含 $n$ 個布林變數的運算式，每個變數有 $0$ 或 $1$ 兩種可能。
- 系統性列舉完整的真值表（共 $2^n$ 種可能的組合）。
- 逐一驗證每個賦值組合是否使整個運算式為 True。若存在至少一組解使運算式為 True，則為 SAT；若全為 False，則為 UNSAT。

## 2. 演算法複雜度
- **時間複雜度**：$O(2^n \cdot m)$，其中 $n$ 為布林變數個數，$m$ 為子句或運算式的長度。當變數數量 $n$ 增加時，計算時間呈指數級別爆炸成長。
- **空間複雜度**：$O(n)$，遞迴深度或維護當前變數賦值所需的空間。

## 3. 執行結果
- 測試運算式：`(A or B) and (not A or C) and (not B or not C)`
- 成功列舉出 $2^3 = 8$ 種真值表組合，並找出所有使運算式成立的滿足解（如 `A=True, B=False, C=True`）。
