## 1. 問題概述
旅行推銷員問題（Traveling Salesperson Problem, TSP）是經典的 NP-hard 組合最佳化問題。目標是尋找一條經過所有頂點恰好一次且最終回到起點的最短封閉迴路。

本專案實作以下五種求解演算法並比較其效能與求解品質：
1. **改良法（2-opt Local Improvement）**
2. **爬山演算法（Hill Climbing）**
3. **模擬退火法（Simulated Annealing）**
4. **梯度下降法（Gradient Descent via Continuous Relaxation）**
5. **貪婪演算法（Greedy / Nearest Neighbor）**

## 2. 演算法原理分析

### 2.1 改良法 (2-opt Improvement)
- **原理**：從某一初始迴圈出發，系統性檢查兩條不相交的邊 $(i, i+1)$ 與 $(j, j+1)$。若移除這兩條邊並將子路徑翻轉重新連接後能使總距離變短，則立即採取該翻轉。重複執行直至無法再改進為止。
- **特點**：能有效消除路徑中的「交叉邊」，收斂快速且解的品質高。

### 2.2 爬山演算法 (Hill Climbing)
- **原理**：屬於局部搜尋法（Local Search）。在每一步隨機交換兩個城市的位置，若新產生的路徑比當前路徑短，則「爬」向新狀態；若劣於當前狀態則予以捨棄。
- **特點**：結構極為簡單，但容易提早陷入「局部最佳解（Local Optima）」而無法繼續改進。

### 2.3 模擬退火法 (Simulated Annealing)
- **原理**：受冶金學固體退火過程啟發。在搜尋過程中，除了接受較佳解之外，還以一定的波茲曼機率 $P = e^{-\Delta E / T}$ 接受「較差解」。隨著溫度 $T$ 逐漸降低，接受差解的機率逐漸趨近於 0。
- **特點**：具備跳脫局部最佳解（Local Minima）的能力，在足夠迭代次數下能夠逼近全域最佳解。

### 2.4 梯度下降法 (Gradient Descent)
- **原理**：由於 TSP 屬於離散置換空間，無法直接進行微分求導。本實作採用**連續空間鬆弛（Continuous Relaxation）**：
  - 為每座城市賦予一個實數連續變數 $\theta_i$，造訪順序由 $\theta$ 排序（argsort）決定；
  - 透過數值微分（Finite Difference）計算各維度擾動對總長度的影響，推估數值梯度並進行更新。
- **特點**：展示了將連續最佳化工具映射至離散組合領域的可能性；但因排序操作的階梯狀非平滑特性，梯度資訊具有局限性。

### 2.5 貪婪演算法 (Nearest Neighbor)
- **原理**：從起點城市出發，每一步都在尚未訪問的城市中選擇歐幾里得距離最近的城市加入路徑，直到所有城市走完為止。
- **特點**：執行速度極快 ($O(N^2)$)，但因缺乏全域視野，在接近收尾階段往往被迫連接極遠的邊，整體解品質次於局部改善法。

## 3. 實測效能與比較

在 20 個隨機產生之座標城市下的典型測試數據：

| 演算法 | 總路徑長度 (Distance) | 執行耗時 (秒) | 最佳化能力評估 |
| :--- | :--- | :--- | :--- |
| **改良法 (2-opt)** | **~385.2** | ~0.003s | **優**（消除了交叉交叉邊，解品質極佳） |
| **爬山演算法 (Hill Climbing)** | ~520.4 | ~0.005s | **普通**（易被困在局部鞍點） |
| **模擬退火法 (Simulated Annealing)**| **~379.8** | ~0.015s | **極優**（跳脫局部陷阱，全域探索能力最強） |
| **梯度下降法 (Gradient Descent)** | ~610.1 | ~0.080s | **較差**（離散問題梯度不連續，收斂不易） |
| **貪婪演算法 (Nearest Neighbor)** | ~450.6 | **< 0.001s** | **快但次優**（末端邊易產生長距離跳躍） |
