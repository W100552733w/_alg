## 1. 簡介與理論說明
Lambda Calculus（$\lambda$-演算）是由阿隆佐·邱奇（Alonzo Church）於 1930 年代提出的形式系統，為所有函數式編程語言的理論基石。

本專案實作了一個具備完整 $\beta$-歸約追蹤過程的 Lambda Calculus 解譯器：
- **語法元素**：
  - **變數（Variable）**：如 `x`, `y`
  - **抽象（Abstraction）**：如 `λx. M`（即匿名函數）
  - **應用（Application）**：如 `(M N)`（即函數呼叫）
- **歸約策略**：採用**正規序歸約（Normal Order Reduction / Call by Name）**，每次選取語法樹中最左且最外層的 Redex 進行替換，確保若運算式存在正規形式（Normal Form），必然能夠化簡完成。
- **變數捕捉處理**：在替換時自動檢測自由變數，必要時進行 **$\alpha$-轉換（Alpha-conversion / 重新命名）**，避免自由變數被意外綁定。

## 2. 測試範例與計算過程展示

### 測試一：布林運算 `NOT TRUE`
- **運算式**：`((λb.((b (λt.(λf.f))) (λt.(λf.t)))) (λt.(λf.t)))`
- **計算步驟記錄**：
  ```text
  步驟 01 => (((λt.(λf.t)) (λt.(λf.f))) (λt.(λf.t)))
  步驟 02 => ((λf.(λt.(λf.f))) (λt.(λf.t)))
  步驟 03 => (λt.(λf.f))
  
  [化簡完成] 最終正規形式: (λt.(λf.f))  # 成功化簡為 FALSE
