## 2. 各演算法原理與實作解析

### 2.1 老鼠走迷宮 (DFS)
- **演算法**：深度優先搜尋（Depth-First Search）。
- **原理**：老鼠從起點出發，沿著特定方向（上、右、下、左）持續深入走訪。當遇到死胡同或障礙物時觸發回溯（Backtracking），退回上一個分支點嘗試其他方向，直到抵達出口。
- **複雜度**：
  - 時間複雜度：$O(V + E) = O(R \times C)$，最差情況下走訪矩陣中所有可行格子。
  - 空間複雜度：$O(R \times C)$，主要為遞迴呼叫堆疊與走訪紀錄所佔之空間。

### 2.2 狼羊甘藍菜過河問題 (BFS)
- **演算法**：廣度優先搜尋（Breadth-First Search）。
- **原理**：將系統狀態定義為四元組 `(人, 狼, 羊, 菜)`，每個元素為 0（此岸）或 1（彼岸）。定義狀態合法性約束（農夫不在時，狼不與羊同側、羊不與菜同側）。利用 FIFO 隊列（Queue）由淺入深層層擴展，保證找出的過河步驟數為**全域最短步數**。
- **結果**：在不違反約束下，最少需 7 次渡河動作完成全體過河。

### 2.3 八皇后問題 (DFS / 回溯法)
- **演算法**：回溯法（DFS with Pruning）。
- **原理**：棋盤為 $8 \times 8$。利用一維陣列記錄每一列皇后的擺放行數。逐列搜尋時進行安全條件判定：檢查是否同列、同行或在對角線上（$|c_1 - c_2| = |r_1 - r_2|$）。若有衝突則立即剪枝回溯，不繼續探索無效分支。
- **結果**：系統性找出全部 92 組無衝突解。

### 2.4 NPC 搜尋玩家 (A* 演算法)
- **演算法**：啟發式搜尋演算法（A* Algorithm）。
- **原理**：
  - 評估函數公式：$f(n) = g(n) + h(n)$
  - $g(n)$：起點到當前節點的實際移動成本（每步代價為 1）。
  - $h(n)$：當前節點到玩家位置的估算成本，本實作採用曼哈頓距離（Manhattan Distance）。
  - 透過 Min-Heap 優先佇列維持當前最優估算節點優先擴展，能夠兼具 BFS 的最短路徑保證以及貪婪搜尋的擴展導向效率。

### 2.5 IC 設計中的電路繞線問題 (Lee 演算法)
- **演算法**：李氏演算法（Lee Algorithm / 迷宮波前擴展法）。
- **原理**：IC 實體設計（Physical Design）中網格繞線（Grid Routing）的基礎方法。
  1. **波前擴展（Wavefront Expansion）**：從 Pin A 開始以 BFS 朝四方未布線網格填入步數 $1, 2, 3, \dots$，如同波浪擴散，直到波前碰觸到 Pin B。
  2. **回溯路徑（Backtracking）**：從 Pin B 開始，依數值遞減（$k, k-1, \dots, 1$）追蹤相鄰格子回到 Pin A，即可保證獲得最少金屬阻抗與轉折的最短路徑。
- **複雜度**：時間與空間皆為 $O(R \times C)$。

## 3. 演算法綜合比較

| 問題 | 使用演算法 | 資料結構 | 最短路徑保證 | 適用情境 |
| :--- | :--- | :--- | :---: | :--- |
| **迷宮尋路** | DFS | 遞迴堆疊 (Call Stack) | 否 | 著重快速找出任一可行解 |
| **渡河問題** | BFS | 佇列 (Queue) | **是** | 狀態空間小且尋求最少步驟 |
| **八皇后** | DFS / 回溯 | 陣列 + 剪枝 | 否（全解） | 組合約束滿足問題 (CSP) |
| **NPC 尋路** | A* | 優先佇列 (Min-Heap) | **是** | 具備幾何坐標與目標明確之地圖導航 |
| **IC 電路繞線** | Lee (BFS 變體) | 網格矩陣 + 佇列 | **是** | 存在障礙區間之晶片網格金屬層連線 |
